# Runtime notices

`MUSL-COPYRIGHT.txt` is the upstream musl copyright and license notice, retrieved
from https://git.musl-libc.org/cgit/musl/plain/COPYRIGHT for the static Linux release.

`scripts/package.py` also includes the installed Rust toolchain's
`COPYRIGHT-library.html` and license/attribution files from dependencies in
Cargo metadata filtered to the release target. These notices are included with release archives rather than
copying vendor GSK software into this repository.
