# GSKRust 0.1.0 — direct CNC file transfer

First public release of a standalone Rust CLI for the GSK Ethernet file protocol. No GSKComm installation, MiniSock.dll, .NET or GUI automation is needed.

## Downloads

- **Windows x64:** `gsk-v0.1.0-windows-x64.zip`, or standalone `gsk-windows-x64.exe`.
- **Linux x64:** `gsk-v0.1.0-linux-x64.tar.gz`, or standalone `gsk-linux-x64` (static musl).
- **Checksums:** `SHA256SUMS.txt`.

Archives include both README languages, protocol notes, hardware evidence, the MIT license and third-party notices. For a standalone download, keep the accompanying notices when redistributing it.

```console
gsk send 192.168.1.100 part.cnc O1234.CNC --verify
gsk receive 192.168.1.100 O1234.CNC received.cnc
gsk list 192.168.1.100
```

## Included

- Upload, download, directory listing, metadata and SHA-256 read-back verification.
- Compatibility shorthand: `gsk IP FILE O1234.CNC`.
- Unicode local paths, local staging, `--no-clobber`, `--dry-run` and explicit exit codes.
- Validated responses, explicit-offset retries and no automatic replay of ambiguous stateful requests.
- Windows x64 and Linux x64 binaries built from the same Rust source.

## Validation

Live controller tests passed for 40-, 80- and 132,557-byte fixtures. Independent receives matched the source bytes. Shorter overwrites truncated correctly. Linux/WSL also exchanged files with the controller. Programs contained only comments and M30 and were never executed.

The loopback suite covers 17 integration scenarios (the POSIX signal case is skipped on Windows), alongside Rust unit tests, formatting and Clippy checks. Full evidence: [hardware report](https://github.com/drockso/gsk-rust/blob/v0.1.0/docs/HARDWARE-2026-11-07.md).

## Limits

Hardware compatibility has been established on one controller, not every GSK model. This is file exchange only: no motion control, program execution, RS-232 or DNC. Uploads replace an existing remote program unless `--no-clobber` is set, and interruption may leave a partial remote file. Use `--verify` to confirm the final content.
